# پروژهٔ نمونهٔ نمایشی — متره‌یار ۳.۰

یک پروژهٔ **کاملاً ناشناس** که کل خطِ لولهٔ متره‌یار را نشان می‌دهد: از
جداولِ Revit تا صورت‌وضعیتِ Excel. برای ارزیابیٔ سریعِ برنامه بدون نیاز به
دادهٔ واقعی.

## فایل‌ها

| فایل | توضیح |
|---|---|
| `project_profile.json` | پروفایل کامل پروژه (مشخصات + تنظیمات). قابلِ بارگذاری در گام ۱ برنامه |
| `sample_output.xlsx` | خروجیِ Excel شش‌برگهٔ تولیدشده |
| `generate_sample.py` | اسکریپتِ تولیدِ دوبارهٔ این دو فایل |

## اجرا

```bash
python examples/sample_project/generate_sample.py
```

ورودی‌ها (خوانده می‌شوند، تغییر نمی‌کنند):

- `data/export revit/` — ۱۰ جدول Schedule
- `data/dynamo/` — نگاشت کد فهرست‌بها
- `data/fehrest baha 1404/` — فهرست‌بهای رسمی

## اعدادِ خروجی (مقیاس‌شده برای ناشناس‌سازی)

برای اینکه پروژهٔ واقعی از روی مبالغ قابلِ شناسایی نباشد، همهٔ قیمت‌های
واحدِ فهرست‌بها در **ضریبِ ثابتِ ۰٫۸** ضرب شده‌اند. کمیت‌ها و ضرایب
(شاخص، بالاسری، منطقه‌ای) دست‌نخورده‌اند، پس همهٔ مبالغ دقیقاً ۰٫۸ برابرِ
پروژهٔ مرجع می‌شوند و منطقِ موتور کاملاً معتبر می‌ماند.

| مقدار | عددِ مقیاس‌شده (ریال) | معادلِ مرجع (×۱٫۲۵) |
|---|---|---|
| baseTotal | ۱۸٬۵۷۴٬۷۰۵٬۰۶۹٫۶۱ | ۲۳٬۲۱۸٬۳۸۱٬۳۳۷٫۰۱ |
| grandTotal | ۲۵٬۱۱۳٬۰۰۱٬۲۵۴٫۱۱ | ۳۱٬۳۹۱٬۲۵۱٬۵۶۷٫۶۴ |
| برآورد به‌هنگام (It=۱۴۰۴Q4) | ۳۶٬۳۵۰٬۱۹۴٬۲۵۶٫۲۶ | ۴۵٬۴۳۷٬۷۴۲٬۸۲۰٫۳۲ |

بازبینی با ابزارِ اعتبارسنجی (ضریب را فراموش نکنید):

```bash
python tools/validate_against_reference.py --xlsx examples/sample_project/sample_output.xlsx --scale 0.8
```

> اعدادِ مرجعِ واقعی (مقیاس ۱) هنوز با `python
> tools/validate_against_reference.py` قابلِ بررسی‌اند و با آزمون‌های
> T112/T113 در هر دو زبان قفل شده‌اند.

## تنظیماتِ فعال

- **حالتِ نمایشی (demo_mode) روشن است** (فاز E-10.1 §۳): هر خروجیِ Excel و
  هر صفحهٔ برنامه واترمارکِ «نسخهٔ نمایشی – اعتبارسنجی‌نشده با صورت‌وضعیت
  تأییدشده» را می‌گیرد. این پروژه نمونه است، نه صورت‌وضعیتِ واقعی.
- هر دو موتور فعال و تأییدشده: **تعدیل پیمان** و **برآورد به‌هنگام**.
- دورهٔ هدف (It) = **۱۴۰۴Q4** (قطعی).
- ضریب k = ۰٫۹۵ (بند ۱-۸)، گردکردنِ بندها به ۲ رقم (بند ۸-۲).
- ضرایب: بالاسری ۱٫۳، منطقه‌ای ۱٫۰۴ (گرگان)، طبقات ۱ (ناقص).
- کسورات: بیمه ۷٫۸٪، مالیات ۵٪، حسن انجام کار ۱۰٪.

## ناشناس بودن

تمامِ مشخصاتِ شناسایی‌کننده (نام پروژه، کارفرما، پیمانکار، مشاور، شمارهٔ
پیمان) الکی هستند. علاوه بر این، همهٔ **مبالغِ مالی با ضریبِ ثابتِ ۰٫۸**
مقیاس شده‌اند (§۶.۳ بالا) تا پروژهٔ واقعی از روی جمعِ کل یا برآورد قابلِ
شناسایی نباشد. کمیت‌ها (مساحت‌ها، وزنِ میلگرد و ...) عمومی هستند و به‌تنهایی
هیچ پروژهٔ خصوصی‌ای را مشخص نمی‌کنند.
