# متره‌یار هوشمند — نسخهٔ ۳.۰ (تک‌فایل Streamlit)

سامانهٔ **دفتر فنی خودکار** برای پروژه‌های ساختمانی ایران — یک فایل واحد `app.py` که خروجی‌های Revit/Dynamo را می‌خواند و صورت‌وضعیت رسمی بر مبنای **فهرست‌بهای واحد پایهٔ رشتهٔ ابنیه ۱۴۰۴** تولید می‌کند.

## نصب و اجرا

```bash
pip install streamlit pandas openpyxl xlsxwriter -i https://mirror-pypi.runflare.com/simple --trusted-host mirror-pypi.runflare.com

streamlit run app.py
```

کد فقط از همین ۴ کتابخانه (+ کتابخانه‌های استاندارد داخلی پایتون مثل `difflib`, `csv`, `io`, `json`, `re`, `datetime`, `logging`) استفاده می‌کند. تاریخ شمسی، تبدیل عدد به حروف و موتور تطبیق فازی همگی دست‌نویس و داخل همین فایل پیاده‌سازی شده‌اند.

## جریان کار (۶ گام)

1. **داشبورد** — دکمهٔ «آزمایش با پروژهٔ نمونه (دمو)» کل خط لوله را با یک زیرمجموعهٔ نمایشی از داده‌های Revit اجرا می‌کند (دادهٔ کامل پروژهٔ مرجع نیست — برای پروژهٔ واقعی، فایل‌های `data/export revit` را در گام ۳ آپلود کنید).
2. **فهرست‌بها** — فایل متن/CSV فهرست‌بها (`کد | فصل | شرح | واحد | بها`) را بارگذاری کنید تا ارقام رسمی جایگزین ردیف‌های تخمینی شود؛ بها هر ردیف در جدول قابل ویرایش است.
3. **جداول Revit** — خروجی‌های Schedule (بتن، قالب‌بندی، آرماتور، تیرچه‌بلوک و …) و فایل Mapping داینامو را بارگذاری کنید؛ نوع هر جدول خودکار تشخیص داده می‌شود.
4. **تنظیمات دفتر فنی** — مشخصات پروژه/قرارداد، متادیتای صورت‌وضعیت (شماره، موقت/قطعی، تاریخ شروع/پایان شمسی با اعتبارسنجی)، ضرایب (پیمان، بالاسری، منطقه‌ای، طبقات، تجهیز کارگاه، مابه‌التفاوت)، کسورات (بیمه ۷٫۸٪، مالیات ۵٪، حسن انجام کار ۱۰٪، پیش‌پرداخت) و تنظیمات نمایش (ریال/تومان، رند).
5. **تطبیق هوشمند** — هر ردیف با درجهٔ اطمینان نمایش داده می‌شود؛ نامزد جایگزین انتخاب کنید، بها را اصلاح کنید یا ردیف را مستثنا کنید.
6. **گزارش‌ها و خروجی** — خلاصهٔ مالی (ناخالص → ضرایب → کسورات → خالص + به حروف فارسی)، خلاصه‌متره فصل‌به‌فصل، ریزمترهٔ ردیابی‌پذیر، لیستوفر آرماتور، آنالیز کیفیت، **سوابق تجمعی** با «کارکرد این دوره»، و دانلود **Excel شش‌برگه** با هدر رسمی (xlsxwriter، راست‌به‌چپ) + JSON.

## نکات فنی موتور

- مقادیر آرماتور با «Grand total» رسمی جدول Revit تراز می‌شود (بدون افت وزن).
- حجم بتن پی در غیاب جدول مستقل، از ابعاد جدول قالب‌بندی پی (طول × عرض × ارتفاع فامیل) استنتاج می‌شود.
- تطبیق فازی: Token-Set Ratio پیاده‌سازی‌شده با `difflib.SequenceMatcher` + امتیاز اشتراک عددی (عیار/قطر).
- پارسر به نام فایل وابسته نیست؛ برای هر پروژهٔ Revit با الگوی مشابه (عنوان فارسی + سرستون انگلیسی) کار می‌کند.
