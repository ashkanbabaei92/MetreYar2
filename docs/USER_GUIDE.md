## ۵. داده‌هایی که باید از کارفرما/مشاور دریافت کنید

این موارد در پنلِ «مقادیر منتظر تأیید» (شیتِ Excel «مقادیر منتظر تأیید» و
`docs/PENDING_DECISIONS.md`) فهرست شده‌اند و تا رسیدنِ سند، خروجی
«پیش‌نویس» می‌ماند:

1. **شاخص کلیِ مستقل** (۱-۲ / ۲-۳ → D-19) — دادهٔ شاخصِ کل کشور لازم است.
2. **مصالحِ پای‌کار** (۲-۴ → D-20) — لیستِ مصالح و کرایه لازم است.
3. **اعدادِ مرجعِ خلاصهٔ ۱۲ مرحله** (ایراد‌های I-15 تا I-18) — سندِ خلاصهٔ ۱۲ مرحله.
4. **تأییدِ تصمیماتِ ثبت‌شده** — ۲۰ تصمیمِ باز (D-01..D-20) در
   `docs/PENDING_DECISIONS.md` (یا `docs/DECISION_SHEET.md`).

## ۶. خروجی‌ها

- **Excel**: ۱۹ شیت — صورت وضعیت، متره ریز، خلاصهٔ مالی و برآورد، لیستوفر
  آرماتور، ضریب طبقات، کیفیت تطبیق، مقادیر منتظر تأیید، هشدارها، قیمت‌های
  دستی، مشخصات پیمان، ضرایب، شاخص‌ها، منابع و بخشنامه‌ها، خلاصه و وضعیت، …
- **پروفایل پروژه** (`project_profile.json`): همهٔ ورودی‌ها برای پروژهٔ بعدی.
- **وارد کردن مجدد**: شیتِ «قیمت‌های دستی» دوباره خوانده می‌شود
  (`parse_manual_entries_xlsx`).

## ۷. پروژهٔ نمونه و اعتبارسنجی

- **پروژهٔ نمونه** (`examples/sample_project/`): پروفایل + Excelِ ازپیش‌تولیدشده
  از یک پروژهٔ کاملاً ناشناس با اعدادِ پروژهٔ مرجع. دوباره تولید:
  `python examples/sample_project/generate_sample.py`.
- **اعتبارسنجیِ اعداد** (`tools/validate_against_reference.py`): موتور یا یک
  فایل Excel را در برابر اعدادِ مرجع با تلرانسِ ۱ ریال بررسی می‌کند:
  ```
  python tools/validate_against_reference.py
  python tools/validate_against_reference.py --xlsx examples/sample_project/sample_output.xlsx
  ```
